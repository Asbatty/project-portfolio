LED Matrix

This is a 64×32 RGB LED matrix driven by an ESP32 and set in a 3D printed frame. I'm working on it now and will fill this page in as it comes together.

Type Personal project
Date 2026 (in progress)
Role CAD, electronics, code

Overview

The heart of this one is a 64×32 RGB LED panel: 2,048 LEDs at a 4 mm pitch, about 10 by 5 inches. An ESP32 drives it, and I'm designing a 3D printed frame to hold the panel and electronics. It's still early, so check back soon for the frame, the wiring, and what it ends up displaying.
