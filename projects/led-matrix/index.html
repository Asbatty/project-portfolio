LED Matrix

I'm building a 64×32 RGB LED matrix into a 3D printed frame, with an ESP32 driving it.

Type Personal project
Date 2026 (in progress)
Role CAD, electronics, code

Overview

The panel is 64×32 RGB, which is 2,048 LEDs at a 4 mm pitch, roughly 10 by 5 inches. An ESP32 drives it, and I'm still designing the frame that holds the panel and electronics. There isn't much to show yet, so this page will fill in once it's lit.
