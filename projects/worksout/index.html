WorksOut

WorksOut is a lifting tracker that lives on my phone. It plans each workout and suggests the next weight from my own history.

Type Web app
Date Sep 2026 – present
Role Solo design & development
Open the app Source on GitHub

Overview

I wanted a workout log that tells me what to do today and how much weight to use, without paying for a subscription or making an account. WorksOut runs entirely on the phone. It works through a rotating program, logs each set with big plus and minus buttons, and saves as I go. The weight suggestions use double progression. Once I hit the top of the rep range on every set, it adds weight. If I fall short, it holds the weight, and after a few misses in a row, it backs off.

How it's built

It's a progressive web app written in TypeScript with React and Vite, hosted on GitHub Pages. Every push runs the unit tests in GitHub Actions before it deploys. React is the only library it needs at runtime, so I wrote the routing, state, progress chart, and icons myself. The scheduling and progression logic are plain functions with Vitest tests, and a validation script checks the program data before each build. There are six programs right now, built from a shared library of 74 exercises.

Not losing anyone's data

Once a few friends started using it, losing data became the real worry. Browsers can clear a site's storage, and iOS Safari is the worst about it. I looked at Google Drive sync, an App Store version, and a hosted database, and went with the option that needs no infrastructure at all. A setup screen has you add the app to your home screen before you enter anything. The app asks the browser to keep its storage, and it reminds you to save a one-tap backup file to iCloud or Drive. Versioned data migrations let me add programs and separate profiles without wiping anyone's history.

What the gym changed

Most of the features came from using it at the gym: sets that collapse once they're done, a rest timer you can drag out of the way, and a 30-minute program for mornings. Using it also turned up a bug. With 5 lb dumbbell jumps, light lifts would bounce between 15 and 20 lb forever. Now it only adds weight when an estimated one-rep max says I can still hit the target reps at the heavier load.
