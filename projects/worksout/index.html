WorksOut

An installable, offline-first lifting tracker that plans each session and suggests the next weight from your own history. Built with React and TypeScript, shared by link.

Type Web app (PWA)
Date Sep 2026 – present
Role Solo — design & development
Open the app Source on GitHub

Overview

I wanted a lifting log that tells me what to do today and what weight to use, without a subscription or an account. WorksOut runs entirely on the phone: it plans the next day of a rolling program, logs sets with large +/- steppers, and saves every tap. Weight suggestions come from my own history using double progression: add load once every set hits the top of the rep range, hold when I fall short, and reset after repeated misses.

Architecture

It's a Vite + React + TypeScript progressive web app, deployed to GitHub Pages by a GitHub Actions workflow that runs the unit tests before every build. React is the only runtime dependency. Routing, state, the progress chart and the icons are all hand-written. Scheduling, progression and history are pure functions covered by Vitest, and a validation script checks the program data (6 programs on a shared library of 74 exercises) before every deploy.

Keeping data safe with no server

Once friends started using it, the hard problem was durability. Browsers, especially iOS Safari, can clear site storage. I compared Google Drive sync, an app-store build and hosted databases, and chose the option with zero infrastructure. A first-run wizard installs the app to the home screen before any data is entered, the app requests persistent storage, and it prompts users to save a one-tap backup to their own iCloud or Drive. Versioned schema migrations let me ship new programs and per-person profiles to live installs without losing anyone's history.

Iterating from real use

Most features came from using it at the gym: sets that fold away as they're done, a draggable rest timer, and a 30-minute program for morning sessions. Real use also exposed a progression bug. Fixed 5 lb dumbbell jumps made light lifts bounce between 15 and 20 lb forever. Now the app only adds weight when an estimated one-rep max says the new load is still achievable for the target reps.
